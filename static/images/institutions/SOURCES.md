# Institution marks

These assets retain the original organizations' colors and proportions.

- `cmu-wordmark.png`: original transparent wordmark from https://www.cmu.edu/mc-assets/wufoo/cmu-wordmark-small.png, linked by CMU's https://www.cmu.edu/web/cascade/managing.html documentation.
- `lti.png`: original Language Technologies Institute image embedded in the Bagpiper-TTS Interspeech 2026 presentation.
- `ly-corporation.png`: original LY Corporation image embedded in the same presentation.
- `nvidia.svg`: original inline wordmark SVG from https://www.nvidia.com/en-us/research/.

The marks identify author affiliations. They remain the property of their respective organizations and are not covered by the website template's license.
